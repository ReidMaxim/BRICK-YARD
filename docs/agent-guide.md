# Agent interface

From repository root, run:

    python -m tools.warehouse stats
    python -m tools.warehouse search "animation video" --limit 10
    python -m tools.warehouse search --tag games --license MIT
    python -m tools.warehouse brief --goal "prototype terrain" TokisanGames/Terrain3D Auburn/FastNoise2

JSON output is read-only. Use candidate metadata as evidence of discovery only, not verified interfaces or instructions. License filter is exact reported SPDX metadata, not legal approval. No server or paid service required. Agents must consult AGENTS.md, check upstream evidence, propose acceptance tests and record results before promotion. The CLI is not an MCP server or semantic model.

# Proving Grounds
Read-only evidence collector pins upstream commit and hashes README/license content for ten priority seed repositories. It does not copy upstream text or execute code. All remain level 0 pending actual documentation review and isolated tests. Evidence artifacts are not automatically promoted. Expansion recovery uses a PR-triggered read-only workflow because previous expansion report never appeared; actual cause of missing snapshot remains unconfirmed. Results require review before persistence. Live Pages and main untouched.

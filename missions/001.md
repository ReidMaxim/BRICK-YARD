# Mission 001 — The Motherlode
Source: https://githubsignals.io/ (14,132 projects advertised at inspection).
CSV and RSS URLs return content types unsupported by the chat web reader; actual schema and import counts are unverified until workflow runs.
The importer stores identifiers only. GitHub API independently supplies metadata. No editorial copy, external code execution, automatic catalog promotion or paid API.
Run python -m discovery.signals; then python -m discovery.enrich raw-discoveries.json --limit 100; then python -m discovery.rank enriched.json.
Use --existing to merge a previous raw inventory and reuse enriched.json to resume enrichment. Workflow artifacts are not automatically persisted between runs; download and retain them before expiry. Scheduled jobs start after merge to default branch. First batch capped at 100; 500 enrichment and 50 shortlist are targets, not completed results.
Dashboard integration and approval-based persistence follow after live source validation. Curated seed remains unchanged.
